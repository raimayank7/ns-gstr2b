ییتہِ GSTR-2B میچ کِتھ کٔرِو

  1. پننؠ پرچیز بِل سیو کٔرِو۔ Nivesh Sahayak App (app.niveshsahayak.in، “Purchases and expenses”) منٛز سپلائرن ہندۍ بِل تہٕ پرچیز ریٹرن درج کٔرِو۔ یِم چھِ یتھ براؤزرکس ڈیٹا ہومس منٛز رِوان۔
  2. GSTR-2B ڈاؤن لوڈ کٔرِو۔ GST پورٹلس پیٹھ: Services › Returns › Returns Dashboard، مدت ژارِو، تہٕ GSTR-2B ٹایلس منٛز Download (JSON یا Excel) ژارِو۔ وُچھِو GSTR-2B کِتھ ڈاؤن لوڈ کٔرِو۔
  3. فایِل ییتہِ کھولِو۔ اپنی GSTR-2B فایِل کھولیں دبٲوِو یا فایِل باکسس پیٹھ ڈراپ کٔرِو۔ تُہندین پرچیز بِلن ہندۍ تٲریخ چھِ 2Bچس مدتس پیٹھ سیٹ گژھان؛ برونٛہہ مہینن ہندۍ بِل آسن تیلہٕ تمن چوڈ کٔرِو۔
  4. فہرستن پیٹھ کام کٔرِو۔ رقم یا تاریخ منٛز فرق تہٕ GSTR-2B منٛز چھُ، تُہندین پرچیز بِلن منٛز نہٕ پیٹھ شروع کٔرِو، پتہٕ سپلائر یمن ہند یتھ GSTR-2B منٛز کیٛنٛہہ نہٕ منٛز آمتین سپلائرن یاد دِیو۔
  5. صحیح ITC کلیم کٔرِو۔ “میچ گمُت ITC” ٹایل چھیہ محفوظ کریڈٹ۔ امہِ ورتاوِو GSTR-3Bچس ٹیبل 4 منٛز (آزماوِو GSTR-3B ورکنگ)۔
  6. کاپی تھاوِو۔ کانٛہہ تہِ فہرست CSV منٛز ڈاؤن لوڈ کٔرِو، یا پوٗرٕ میچ پننس اکاؤنٹنٹس باپتھ PDF پرنٹ کٔرِو۔

یہ کیا چھُ تُہندِ باپتھ کران

  • پورٹلچ دۅشوے فایِلہٕ چھِ پرَان: GSTR-2B JSON تہٕ GSTR-2B Excel، تمن ہندین فیلڈ نامن سٕتۍ، تاکہ فارمیٹ منٛز چھوٹ بدلاو امہِ نہٕ تراوِ۔
  • سپلائر GSTIN تہٕ بِل نمبر سٕتۍ چھُ ملاوان، خالی جاے، سلیش تہٕ شروعاتی صفر نظرانداز کٔرتھ، پتہٕ تُہندِ دِمتِ گنجایش اندر ٹیکس لایق ویلیو، ٹیکس تہٕ تٲریخ جانچان۔
  • ٹائپنگ فرق چھُ پکڑان: سُہے سپلائر تہٕ سُہے رقم مگر الگ بِل نمبر آسہِ، تیلہٕ چھُ غایب نہٕ، الگ ہیکھنہٕ یوان۔
  • ہیکھان کمس پتہٕ گژھُن: 2B مَنزہ غایب بِل، تُہندین کتابن مَنزہ غایب بِل، ITC دستیاب نہٕ والۍ بِل، تہٕ سپلائر یمن کیٛنٛہہ رپورٹ نہٕ کوٚر۔
  • IGST یا CGST + SGST: یمن بِلن منٛز ٹیکس ہیڈ الگ چھُ تِم چھُ نشان کران، یُس غلط پلیس آف سپلائری ہند عام سبب چھُ۔
  • سرکاری ٹولہٕ باپتھ پرچیز رجسٹر: پننؠ بِل GST پورٹلک Matching Offline Tool ٹیمپلیٹچ ترتیب منٛز ڈاؤن لوڈ کٔرِو۔

تُہنٛد ڈیٹا چھُ تُہندس سٕتۍ رِوان

GSTR-2B فایِل چھیہ یتھ براؤزرس اندر کھلان تہٕ پرنہٕ یوان۔ سۅ چھیہ نہٕ اَسہِ یا کتھ بیاکھ اپ لوڈ گژھان، تہٕ نہٕ سیو گژھان: اگلی وارہ دوبارٕ کھولِو۔ تُہند پرچیز بِل چھِ تُہندس Nivesh Sahayak ڈیٹا ہومہٕ (my.niveshsahayak.in) پیٹھ یوان۔

یہ چھیہ جانچ، مشورہ نہٕ۔ میچ چھُ فرق ہیکھان؛ کُس کریڈٹ کلیم کرُن سُہ فیصلہ چھُ تُہند۔ شک آسہِ تیلہٕ پرٛژھِو پننس اکاؤنٹنٹس۔

گائیڈ

GSTR-2B ریکنسلی ایشن، قدم بہ قدمہر نتیجک مطلب تہٕ کیا کرُن۔ GSTR-2B کِتھ ڈاؤن لوڈ کٔرِوپورٹلہٕ پیٹھ JSON یا Excel، تہٕ IMS۔ GSTR-2B بمقابلہ GSTR-2Aتُہنٛد ITC کُس چھُ طے کران، تہٕ کیازِ۔ سپلائرن نہٕ GSTR-1 فایِل کوٚرتُہندس ITCس کیا چھُ گژھان تہٕ کیا کرُن۔

لوکھ کیا چھِ پرٛژھان

کیا چھیہ میٲنۍ GSTR-2B فایِل کتھ اپ لوڈ گژھان؟

نہٕ۔ سۅ چھیہ تُہندس براؤزرس اندر کھلان تہٕ پرنہٕ یوان، نہٕ سیو گژھان نہٕ کتھ سوزنہٕ یوان۔

کُس فایِل کھولو، JSON یا Excel؟

کانٛہہ تہِ۔ GST پورٹلک Returns Dashboard پیٹھ GSTR-2B JSON یا Excel منٛز ڈاؤن لوڈ کٔرِو تہٕ ییتہِ کھولِو۔

میانۍ پرچیز بِل کتھ پیٹھ چھِ یوان؟

تمن پرچیز بِلن تہٕ ریٹرنن پیٹھ یم تۅہہ Nivesh Sahayak App منٛز لیکھ تہٕ یم یتھ براؤزرکس ڈیٹا ہومس منٛز سیو چھِ۔

کانٛہہ بِل کیازِ چھُ “بِل نمبر منٛز فرق” ہیکھان؟

سپلائرُک GSTIN تہٕ رقمہٕ چھِ اکوے مگر بِل نمبر چھُ بیاکھ لیکھمت، مثلاً “INV/45” تہٕ “45”۔ پننؠ انٹری ٹھیک کٔرِو تاکہ اگلی وارہ میچ گژھہِ۔

کیا ہیکو یہ GST پورٹلک پانہٕ میچنگ ٹول سٕتۍ ورتاوتھ؟

آ۔ “GST میچنگ ٹولہٕ باپتھ پرچیز رجسٹر” دبٲوِو تاکہ تُہند پرچیز بِل پورٹلک Matching Offline Tool ٹیمپلیٹچ ترتیب منٛز میلن۔

کیا چھُ یہ مفت؟

آ، مفت، لاگ اِن بغیر تہٕ کانٛہہ تہِ حد بغیر۔
