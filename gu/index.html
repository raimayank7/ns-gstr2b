તમારાં ખરીદ બિલ માટે મફત GSTR-2B મેચર

GST પોર્ટલ પરથી GSTR-2B ડાઉનલોડ કરો, અહીં ખોલો, અને તરત જુઓ કે કયાં સપ્લાયર બિલ તમારા હિસાબ સાથે મેળ ખાય છે, કયાં અલગ છે, કયાં કોઈ એક બાજુએ નથી અને કયા સપ્લાયરોએ ફાઇલ કર્યું નથી. ફાઇલ તમારા બ્રાઉઝરની બહાર જતી નથી.

અહીં GSTR-2B મેચ કેવી રીતે કરવો

  1. તમારાં ખરીદ બિલ સેવ કરો. સપ્લાયરનાં બિલ અને ખરીદ રિટર્ન Nivesh Sahayak App (app.niveshsahayak.in, “Purchases and expenses”) માં લખો. તે આ બ્રાઉઝરના ડેટા હોમમાં રહે છે.
  2. GSTR-2B ડાઉનલોડ કરો. GST પોર્ટલ પર: Services › Returns › Returns Dashboard, સમયગાળો પસંદ કરો, અને GSTR-2B ટાઇલમાં Download પસંદ કરો (JSON કે Excel). જુઓ GSTR-2B કેવી રીતે ડાઉનલોડ કરવું.
  3. ફાઇલ અહીં ખોલો. તમારી GSTR-2B ફાઇલ ખોલો દબાવો અથવા ફાઇલ બોક્સ પર મૂકો. તમારાં ખરીદ બિલની તારીખો 2B ના સમયગાળા મુજબ ગોઠવાય છે; અગાઉના મહિનાનાં બિલ આવી શકે તેમ હોય તો તેને પહોળી કરો.
  4. યાદીઓ તપાસતા જાઓ. રકમ કે તારીખ અલગ અને GSTR-2B માં છે, તમારાં ખરીદ બિલોમાં નથી થી શરૂ કરો, પછી આ GSTR-2B માં કંઈ ન હોય તેવા સપ્લાયર હેઠળના સપ્લાયરોને યાદ કરાવો.
  5. સાચો ITC ક્લેમ કરો. “મેચ થયેલો ITC” ટાઇલ સલામત ક્રેડિટ છે. તેને GSTR-3B ના ટેબલ 4 માં વાપરો (જુઓ GSTR-3B વર્કિંગ).
  6. નકલ રાખો. કોઈપણ યાદી CSV તરીકે ડાઉનલોડ કરો, અથવા આખો મેચ એકાઉન્ટન્ટ માટે PDF તરીકે પ્રિન્ટ કરો.

આ તમારા માટે શું કરે છે

  • પોર્ટલની બંને ફાઇલ વાંચે છે: GSTR-2B JSON અને GSTR-2B Excel, ફીલ્ડના નામ મુજબ, એટલે ફૉર્મેટમાં નાના ફેરફારથી તે અટકતું નથી.
  • સપ્લાયરનો GSTIN અને બિલ નંબરથી મેળવે છે, સ્પેસ, સ્લૅશ અને આગળના શૂન્ય ગણ્યા વગર, પછી તમે આપેલા તફાવતમાં કરપાત્ર મૂલ્ય, ટેક્સ અને તારીખ તપાસે છે.
  • ટાઇપિંગનો તફાવત શોધે છે: સપ્લાયર અને રકમ સરખાં પણ બિલ નંબર અલગ હોય તો તેને “ગુમ” તરીકે નહીં, અલગ બતાવે છે.
  • શેનો પીછો કરવો તે બતાવે છે: 2B માં ન હોય તેવાં બિલ, તમારા હિસાબમાં ન હોય તેવાં બિલ, ITC ઉપલબ્ધ નથી એવાં બિલ, અને કંઈ ન જણાવનાર સપ્લાયર.
  • IGST કે CGST + SGST: ટેક્સ હેડ અલગ હોય તેવાં બિલ બતાવે છે, જે ખોટા પ્લેસ ઑફ સપ્લાયનું સામાન્ય કારણ છે.
  • સત્તાવાર ટૂલ માટે ખરીદ રજિસ્ટર: GST પોર્ટલના Matching Offline Tool ટેમ્પ્લેટના લેઆઉટમાં તમારાં બિલ ડાઉનલોડ કરો.

તમારો ડેટા તમારી પાસે જ રહે છે

GSTR-2B ફાઇલ આ બ્રાઉઝરમાં જ ખોલાય અને વંચાય છે. તે અમને કે બીજે ક્યાંય અપલોડ થતી નથી અને સેવ પણ થતી નથી: આવતી વખતે ફરી ખોલો. તમારાં ખરીદ બિલ તમારા Nivesh Sahayak ડેટા હોમમાંથી (my.niveshsahayak.in) આવે છે.

આ તપાસ છે, સલાહ નથી. મેચ તફાવત બતાવે છે; કયું ક્રેડિટ ક્લેમ કરવું તે નિર્ણય તમારો છે. શંકા હોય તો તમારા એકાઉન્ટન્ટને પૂછો.

માર્ગદર્શિકાઓ

GSTR-2B રિકન્સિલિએશન, પગલે પગલેદરેક પરિણામનો અર્થ અને શું કરવું. GSTR-2B કેવી રીતે ડાઉનલોડ કરવુંપોર્ટલ પરથી JSON કે Excel, અને IMS. GSTR-2B વિરુદ્ધ GSTR-2Aતમારો ITC કયું નક્કી કરે છે અને કેમ. સપ્લાયરે GSTR-1 ફાઇલ કર્યું નથીતમારા ITC નું શું થાય અને શું કરવું.

લોકો પૂછે છે તે પ્રશ્નો

શું મારી GSTR-2B ફાઇલ ક્યાંય અપલોડ થાય છે?

ના. તે તમારા બ્રાઉઝરમાં જ ખોલાય અને વંચાય છે, સેવ કે ક્યાંય મોકલાતી નથી.

કઈ ફાઇલ ખોલવી, JSON કે Excel?

બંને ચાલે. GST પોર્ટલના Returns Dashboard પરથી GSTR-2B JSON કે Excel માં ડાઉનલોડ કરો અને અહીં ખોલો.

મારાં ખરીદ બિલ ક્યાંથી આવે છે?

તમે Nivesh Sahayak App માં લખેલાં ખરીદ બિલ અને રિટર્નમાંથી, જે આ બ્રાઉઝરના ડેટા હોમમાં સેવ હોય છે.

બિલ “નંબર અલગ” કેમ બતાવાય છે?

સપ્લાયરનો GSTIN અને રકમ મળે છે પણ બિલ નંબર અલગ રીતે લખાયો હોય છે, દા.ત. “INV/45” અને “45”. આવતી વખતે મેળ ખાય તે માટે તમારી એન્ટ્રી સુધારો.

શું GST પોર્ટલના પોતાના મેચિંગ ટૂલ સાથે વાપરી શકાય?

હા. “GST મેચિંગ ટૂલ માટે ખરીદ રજિસ્ટર” દબાવો, એટલે તમારાં ખરીદ બિલ પોર્ટલના Matching Offline Tool ટેમ્પ્લેટના લેઆઉટમાં મળે છે.

શું આ મફત છે?

હા, મફત, લૉગિન નહીં અને કોઈ મર્યાદા નહીં.
