GST पोर्टल सँ GSTR-2B उतारू, एतय खोलू, आ तुरंत देखू जे कोन सप्लायर बिल अहाँक बही सँ मेल खाइत अछि, कोन फराक अछि, कोन कोनो एक दिस गायब अछि, आ कोन सप्लायर फ़ाइल नहि कएने छथि। फ़ाइल अहाँक ब्राउज़र सँ बाहर नहि जाइत अछि।

एतय GSTR-2B मिलान केना करू

  1. अपन पर्चेज बिल सेव करू। सप्लायर बिल आ पर्चेज रिटर्न Nivesh Sahayak ऐप (app.niveshsahayak.in, “Purchases and expenses”) मे भरू। ओ एहि ब्राउज़रक डेटा होम मे रहैत अछि।
  2. GSTR-2B उतारू। GST पोर्टल पर: Services › Returns › Returns Dashboard, अवधि चुनू, आ GSTR-2B बला टाइल मे Download (JSON वा Excel) चुनू। देखू GSTR-2B केना उतारू।
  3. फ़ाइल एतय खोलू। अपन GSTR-2B फ़ाइल खोलू दबाउ वा फ़ाइल डिब्बा पर छोड़ि दिअ। अहाँक पर्चेज बिलक तारीख 2B अवधि पर सेट होइत अछि; पहिनुका मासक बिल अएबाक आशंका हो तँ ओकरा चौड़ा कए लिअ।
  4. लिस्ट एक-एक कए देखू। रकम वा तारीख फराक अछि आ GSTR-2B मे अछि, अहाँक पर्चेज बिल मे नहि अछि सँ शुरू करू, फेर एहि GSTR-2B मे जिनकर किछु नहि अछि ओ सप्लायर मे जिनकर नाम अछि तिनका मोन पाड़ू।
  5. सही ITC क्लेम करू। “मेल खाएबला ITC” बला टाइल सुरक्षित क्रेडिट थिक। एकरा GSTR-3B क टेबल 4 मे इस्तेमाल करू (देखू GSTR-3B वर्किंग)।
  6. एकटा कॉपी राखू। कोनो लिस्ट CSV मे उतारू, वा पूरा मिलान अकाउंटेंट लेल PDF मे प्रिंट करू।

ई अहाँक लेल की करैत अछि

  • पोर्टलक दुनू फ़ाइल पढ़ैत अछि: GSTR-2B JSON आ GSTR-2B Excel, ओकर फ़ील्ड नाम सँ, तेँ छोट-मोट फ़ॉर्मेट बदलाव सँ ई नहि टूटैत अछि।
  • सप्लायर GSTIN आ बिल नंबर सँ मिलबैत अछि, खाली जगह, स्लैश आ आगाँक शून्य केँ छोड़ि कए, फेर अहाँक तय कएल अंतरक भीतर टैक्सेबल वैल्यू, टैक्स आ तारीख जाँचैत अछि।
  • टाइपिंगक अंतर पकड़ैत अछि: एके सप्लायर आ एके रकम मुदा फराक बिल नंबर, तँ गायब नहि, अलग देखाओल जाइत अछि।
  • पाछाँ लगबाक चीज देखबैत अछि: 2B सँ गायब बिल, अहाँक बही सँ गायब बिल, ITC नहि भेटत बला निशान, आ ओ सप्लायर जे किछु रिपोर्ट नहि कएलनि।
  • IGST वा CGST + SGST: जतय टैक्स हेड फराक अछि ओ बिल चिन्हित करैत अछि, जे गलत प्लेस ऑफ़ सप्लाईक सामान्य कारण थिक।
  • सरकारी टूल लेल पर्चेज रजिस्टर: अपन बिल GST पोर्टलक Matching Offline Tool टेम्पलेटक लेआउट मे उतारू।

अहाँक डेटा अहीं लग रहैत अछि

GSTR-2B फ़ाइल एही ब्राउज़र मे खोलल आ पढ़ल जाइत अछि। ओ हमरा सभ केँ वा कतहु आन ठाम नहि पठाओल जाइत अछि, आ सेव सेहो नहि होइत अछि: अगिला बेर फेर खोलू। अहाँक पर्चेज बिल अहाँक Nivesh Sahayak डेटा होम (my.niveshsahayak.in) सँ अबैत अछि।

जाँच अछि, सलाह नहि। मिलान अंतर देखबैत अछि; कोन क्रेडिट क्लेम करब से अहाँ तय करैत छी। शक होअय तँ अपन अकाउंटेंट सँ पूछू।

गाइड

GSTR-2B रिकंसिलिएशन, कदम-कदमप्रत्येक नतीजाक मतलब आ की करबाक अछि। GSTR-2B केना उतारूपोर्टल सँ JSON वा Excel, आ IMS। GSTR-2B बनाम GSTR-2Aकोन एक अहाँक ITC तय करैत अछि, आ किएक। सप्लायर GSTR-1 फ़ाइल नहि कएलनिअहाँक ITC केँ की होइत अछि आ की करू।

लोक की पूछैत अछि

की हमर GSTR-2B फ़ाइल कतहु अपलोड होइत अछि?

नहि। ओ अहाँक ब्राउज़र मे खुलैत आ पढ़ल जाइत अछि, आ कतहु सेव वा पठाओल नहि जाइत अछि।

कोन फ़ाइल खोलू, JSON वा Excel?

कोनो चलत। GST पोर्टलक Returns Dashboard सँ GSTR-2B JSON वा Excel मे उतारू आ एतय खोलू।

हमर पर्चेज बिल कतय सँ अबैत अछि?

Nivesh Sahayak ऐप मे अहाँक भरल पर्चेज बिल आ रिटर्न सँ, जे एहि ब्राउज़रक डेटा होम मे सेव अछि।

बिल “नंबर फराक अछि” किएक देखाओल जाइत अछि?

सप्लायरक GSTIN आ रकम मेल खाइत अछि मुदा बिल नंबर फराक लिखल अछि, जेना “INV/45” आ “45”। अपन एंट्री ठीक कए लिअ, अगिला बेर मेल खा जाएत।

की एकरा GST पोर्टलक अपन मैचिंग टूल क संग इस्तेमाल कए सकैत छी?

हँ। “GST मैचिंग टूल लेल पर्चेज रजिस्टर” दबाए कए अपन पर्चेज बिल पोर्टलक Matching Offline Tool टेम्पलेटक लेआउट मे पाउ।

की ई फ्री अछि?

हँ, फ्री अछि, ने लॉगिन चाही, ने कोनो सीमा।
