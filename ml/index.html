2B റീകൺസിലിയേഷൻGSTR-2B ഡൗൺലോഡ്Nivesh Sahayak App

നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകൾക്കുള്ള സൗജന്യ GSTR-2B മാച്ചർ

GST പോർട്ടലിൽ നിന്ന് GSTR-2B ഡൗൺലോഡ് ചെയ്ത് ഇവിടെ തുറക്കുക, ഏത് സപ്ലയർ ബില്ലുകൾ നിങ്ങളുടെ പുസ്തകവുമായി ഒത്തുപോകുന്നു, ഏതൊക്കെ വ്യത്യസ്തമാണ്, ഏതൊക്കെ ഇരുവശത്തും ഇല്ല, ഏത് സപ്ലയർമാർ ഫയൽ ചെയ്തിട്ടില്ല എന്ന് ഉടൻ കാണുക. ഫയൽ നിങ്ങളുടെ ബ്രൗസർ വിട്ടുപോകില്ല.

ഇവിടെ GSTR-2B മാച്ച് ചെയ്യുന്നത് എങ്ങനെ

  1. നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകൾ സേവ് ചെയ്യുക. സപ്ലയർ ബില്ലുകളും പർച്ചേസ് റിട്ടേണുകളും Nivesh Sahayak App ൽ (app.niveshsahayak.in, "Purchases and expenses") എൻട്രി ചെയ്യുക. അവ ഈ ബ്രൗസറിന്റെ ഡേറ്റാ ഹോമിൽ സൂക്ഷിക്കും.
  2. GSTR-2B ഡൗൺലോഡ് ചെയ്യുക. GST പോർട്ടലിൽ: Services › Returns › Returns Dashboard, കാലയളവ് തിരഞ്ഞെടുത്ത് GSTR-2B ടൈലിൽ Download തിരഞ്ഞെടുക്കുക (JSON അല്ലെങ്കിൽ Excel). GSTR-2B എങ്ങനെ ഡൗൺലോഡ് ചെയ്യാം കാണുക.
  3. ഫയൽ ഇവിടെ തുറക്കുക. നിങ്ങളുടെ GSTR-2B ഫയൽ തുറക്കുക അമർത്തുക അല്ലെങ്കിൽ ഫയൽ ബോക്സിലേക്ക് ഇടുക. നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകളുടെ തീയതികൾ 2B കാലയളവിലേക്ക് സജ്ജമാക്കും; മുൻ മാസങ്ങളിലെ ബില്ലുകളും വരാൻ സാധ്യതയുണ്ടെങ്കിൽ വിശാലമാക്കുക.
  4. പട്ടികകൾ നോക്കുക. തുകയോ തീയതിയോ വ്യത്യസ്തം, GSTR-2B യിൽ ഉണ്ട്, നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകളിൽ ഇല്ല എന്നിവയിൽ നിന്ന് തുടങ്ങുക, പിന്നെ ഈ GSTR-2B യിൽ ഒന്നുമില്ലാത്ത സപ്ലയർമാർ ക്ക് ഓർമ്മപ്പെടുത്തുക.
  5. ശരിയായ ITC ക്ലെയിം ചെയ്യുക. "മാച്ച് ആയ ITC" ടൈൽ സുരക്ഷിതമായ ക്രെഡിറ്റ് ആണ്. അത് GSTR-3B യുടെ ടേബിൾ 4 ൽ ഉപയോഗിക്കുക (GSTR-3B വർക്കിംഗ് പരീക്ഷിക്കുക).
  6. ഒരു കോപ്പി സൂക്ഷിക്കുക. ഏത് പട്ടികയും CSV ആയി ഡൗൺലോഡ് ചെയ്യുക, അല്ലെങ്കിൽ മുഴുവൻ മാച്ച് അക്കൗണ്ടന്റിനായി PDF ആയി പ്രിന്റ് ചെയ്യുക.

ഇത് നിങ്ങൾക്ക് വേണ്ടി എന്തു ചെയ്യുന്നു

  • പോർട്ടലിന്റെ രണ്ട് ഫയലുകളും വായിക്കുന്നു: GSTR-2B JSON ഉം GSTR-2B Excel ഉം, അവയുടെ ഫീൽഡ് പേരുകൾ വഴി, അതിനാൽ ചെറിയ ഫോർമാറ്റ് മാറ്റങ്ങൾ ഇതിനെ തകർക്കില്ല.
  • സപ്ലയർ GSTIN, ബിൽ നമ്പർ എന്നിവ വച്ച് മാച്ച് ചെയ്യുന്നു, സ്പേസ്, സ്ലാഷ്, മുന്നിലെ പൂജ്യങ്ങൾ എന്നിവ അവഗണിച്ച്, പിന്നെ നിങ്ങൾ അനുവദിക്കുന്ന വ്യത്യാസത്തിനുള്ളിൽ ടാക്സബിൾ വാല്യു, ടാക്സ്, തീയതി പരിശോധിക്കുന്നു.
  • ടൈപ്പിംഗ് വ്യത്യാസങ്ങൾ കണ്ടെത്തുന്നു: അതേ സപ്ലയർ, അതേ തുക, വ്യത്യസ്ത ബിൽ നമ്പർ ആണെങ്കിൽ "ഇല്ല" എന്ന് പറയാതെ പ്രത്യേകം കാണിക്കുന്നു.
  • എന്ത് പിന്തുടരണമെന്ന് കാണിക്കുന്നു: 2B യിൽ ഇല്ലാത്ത ബില്ലുകൾ, നിങ്ങളുടെ പുസ്തകത്തിൽ ഇല്ലാത്ത ബില്ലുകൾ, ITC ലഭ്യമല്ല എന്ന് അടയാളപ്പെടുത്തിയവ, ഒന്നും റിപ്പോർട്ട് ചെയ്യാത്ത സപ്ലയർമാർ.
  • IGST അല്ലെങ്കിൽ CGST + SGST: ടാക്സ് ഹെഡ് വ്യത്യസ്തമായ ബില്ലുകൾ അടയാളപ്പെടുത്തുന്നു, തെറ്റായ വിതരണ സ്ഥലത്തിന്റെ സാധാരണ കാരണം.
  • ഔദ്യോഗിക ടൂളിനുള്ള പർച്ചേസ് രജിസ്റ്റർ: GST പോർട്ടലിന്റെ Matching Offline Tool ടെംപ്ലേറ്റിന്റെ ലേഔട്ടിൽ നിങ്ങളുടെ ബില്ലുകൾ ഡൗൺലോഡ് ചെയ്യുക.

നിങ്ങളുടെ ഡേറ്റാ നിങ്ങളുടെ കൈവശം തന്നെ

GSTR-2B ഫയൽ ഈ ബ്രൗസറിനുള്ളിൽ തുറന്ന് വായിക്കുന്നു. അത് ഞങ്ങൾക്കോ മറ്റെവിടെയെങ്കിലുമോ അപ്‌ലോഡ് ചെയ്യുന്നില്ല, സേവ് ചെയ്യുന്നുമില്ല: അടുത്ത തവണ വീണ്ടും തുറക്കുക. നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകൾ നിങ്ങളുടെ Nivesh Sahayak ഡേറ്റാ ഹോമിൽ (my.niveshsahayak.in) നിന്ന് വരുന്നു.

ഇത് ഒരു പരിശോധനയാണ്, ഉപദേശമല്ല. മാച്ച് വ്യത്യാസങ്ങൾ കാണിക്കുന്നു; ഏത് ക്രെഡിറ്റ് ക്ലെയിം ചെയ്യണമെന്ന തീരുമാനം നിങ്ങളുടേതാണ്. സംശയമുണ്ടെങ്കിൽ നിങ്ങളുടെ അക്കൗണ്ടന്റിനോട് ചോദിക്കുക.

ഗൈഡുകൾ

GSTR-2B റീകൺസിലിയേഷൻ, ഘട്ടം ഘട്ടമായിഓരോ ഫലത്തിന്റെയും അർത്ഥവും എന്തു ചെയ്യണമെന്നും. GSTR-2B എങ്ങനെ ഡൗൺലോഡ് ചെയ്യാംപോർട്ടലിൽ നിന്ന് JSON അല്ലെങ്കിൽ Excel, IMS. GSTR-2B vs GSTR-2Aഏതാണ് നിങ്ങളുടെ ITC തീരുമാനിക്കുന്നത്, എന്തുകൊണ്ട്. സപ്ലയർ GSTR-1 ഫയൽ ചെയ്തിട്ടില്ലനിങ്ങളുടെ ITC ക്ക് എന്ത് സംഭവിക്കും, എന്ത് ചെയ്യണം.

ആളുകൾ ചോദിക്കുന്ന ചോദ്യങ്ങൾ

എന്റെ GSTR-2B ഫയൽ എവിടെയെങ്കിലും അപ്‌ലോഡ് ചെയ്യുമോ?

ഇല്ല. അത് നിങ്ങളുടെ ബ്രൗസറിനുള്ളിൽ തുറന്ന് വായിക്കുന്നു, സേവ് ചെയ്യുകയോ എവിടെയും അയയ്ക്കുകയോ ചെയ്യുന്നില്ല.

ഏത് ഫയൽ തുറക്കണം, JSON അല്ലെങ്കിൽ Excel?

ഏതും. GST പോർട്ടലിന്റെ Returns Dashboard ൽ നിന്ന് GSTR-2B JSON അല്ലെങ്കിൽ Excel ആയി ഡൗൺലോഡ് ചെയ്ത് ഇവിടെ തുറക്കുക.

എന്റെ പർച്ചേസ് ബില്ലുകൾ എവിടെ നിന്ന് വരുന്നു?

നിങ്ങൾ Nivesh Sahayak App ൽ എൻട്രി ചെയ്ത് ഈ ബ്രൗസറിന്റെ ഡേറ്റാ ഹോമിൽ സേവ് ചെയ്ത പർച്ചേസ് ബില്ലുകളിലും റിട്ടേണുകളിലും നിന്ന്.

ഒരു ബിൽ "നമ്പർ വ്യത്യസ്തം" എന്ന് കാണിക്കുന്നത് എന്തുകൊണ്ട്?

സപ്ലയറുടെ GSTIN യും തുകകളും ഒത്തുപോകുന്നു, പക്ഷേ ബിൽ നമ്പർ വേറെ രീതിയിൽ എഴുതിയിരിക്കുന്നു, ഉദാഹരണത്തിന് "INV/45" ഉം "45" ഉം. അടുത്ത തവണ ഒത്തുപോകാൻ നിങ്ങളുടെ എൻട്രി തിരുത്തുക.

GST പോർട്ടലിന്റെ സ്വന്തം മാച്ചിംഗ് ടൂളുമായി ഇത് ഉപയോഗിക്കാമോ?

ഉപയോഗിക്കാം. "GST മാച്ചിംഗ് ടൂളിനുള്ള പർച്ചേസ് രജിസ്റ്റർ" അമർത്തിയാൽ നിങ്ങളുടെ പർച്ചേസ് ബില്ലുകൾ പോർട്ടലിന്റെ Matching Offline Tool ടെംപ്ലേറ്റിന്റെ ലേഔട്ടിൽ കിട്ടും.

ഇത് സൗജന്യമാണോ?

അതെ, സൗജന്യം, ലോഗിൻ വേണ്ട, പരിധിയില്ല.
