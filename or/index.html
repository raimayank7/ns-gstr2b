2B ରିକନ୍ସିଲିଏସନ୍GSTR-2B ଡାଉନଲୋଡ୍

ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍ ପାଇଁ ମାଗଣା GSTR-2B ମ୍ୟାଚର୍

GST ପୋର୍ଟାଲରୁ GSTR-2B ଡାଉନଲୋଡ୍ କରନ୍ତୁ, ଏଠାରେ ଖୋଲନ୍ତୁ, ଆଉ ତୁରନ୍ତ ଦେଖନ୍ତୁ କେଉଁ ସପ୍ଲାୟର୍ ବିଲ୍ ଆପଣଙ୍କ ଖାତା ସହିତ ମେଳ ଖାଏ, କେଉଁଟି ଅଲଗା, କେଉଁଟି କେଉଁ ପାଖେ ନାହିଁ ଓ କେଉଁ ସପ୍ଲାୟର୍ ଫାଇଲ୍ କରିନାହାଁନ୍ତି। ଫାଇଲ୍ ଆପଣଙ୍କ ବ୍ରାଉଜରରୁ କେବେ ବାହାରକୁ ଯାଏ ନାହିଁ।

ଏଠାରେ GSTR-2B ମ୍ୟାଚ୍ କିପରି କରିବେ

  1. ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍ ସେଭ୍ କରନ୍ତୁ। Nivesh Sahayak App (app.niveshsahayak.in, “Purchases and expenses”) ରେ ସପ୍ଲାୟର୍ ବିଲ୍ ଓ ପର୍ଚେଜ୍ ରିଟର୍ଣ୍ଣ ଏଣ୍ଟ୍ରି କରନ୍ତୁ। ସେଗୁଡ଼ିକ ଏହି ବ୍ରାଉଜରର ଡାଟା ହୋମ୍‌ରେ ରହେ।
  2. GSTR-2B ଡାଉନଲୋଡ୍ କରନ୍ତୁ। GST ପୋର୍ଟାଲରେ: Services › Returns › Returns Dashboard, ପିରିୟଡ୍ ବାଛନ୍ତୁ, ଆଉ GSTR-2B ଟାଇଲ୍‌ରେ Download (JSON ବା Excel) ବାଛନ୍ତୁ। GSTR-2B କିପରି ଡାଉନଲୋଡ୍ କରିବେ ଦେଖନ୍ତୁ।
  3. ଫାଇଲ୍ ଏଠାରେ ଖୋଲନ୍ତୁ। ଆପଣଙ୍କ GSTR-2B ଫାଇଲ୍ ଖୋଲନ୍ତୁ ଦବାନ୍ତୁ ବା ଫାଇଲ୍‌କୁ ବକ୍ସରେ ଛାଡ଼ନ୍ତୁ। ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍‌ର ତାରିଖ 2B ପିରିୟଡ୍‌କୁ ସେଟ୍ ହୁଏ; ଆଗ ମାସର ବିଲ୍ ଦେଖାଯାଇପାରେ ବୋଲି ଲାଗିଲେ ତାହାକୁ ବଢ଼ାନ୍ତୁ।
  4. ତାଲିକାଗୁଡ଼ିକ ଦେଖନ୍ତୁ। ଅଙ୍କ ବା ତାରିଖ ଅଲଗା ଓ GSTR-2B ରେ ଅଛି, ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍‌ରେ ନାହିଁ ରୁ ଆରମ୍ଭ କରନ୍ତୁ, ତା’ପରେ ଏହି GSTR-2B ରେ କିଛି ନଥିବା ସପ୍ଲାୟର୍ ତଳେ ଥିବା ସପ୍ଲାୟର୍ମାନଙ୍କୁ ମନେ ପକାନ୍ତୁ।
  5. ଠିକ୍ ITC କ୍ଲେମ୍ କରନ୍ତୁ। “ମେଳ ଖାଇଥିବା ITC” ଟାଇଲ୍ ହେଉଛି ସୁରକ୍ଷିତ କ୍ରେଡିଟ୍। ଏହାକୁ GSTR-3B ର ଟେବୁଲ୍ 4 ରେ ବ୍ୟବହାର କରନ୍ତୁ (GSTR-3B ହିସାବ ଦେଖନ୍ତୁ)।
  6. ଏକ କପି ରଖନ୍ତୁ। ଯେକୌଣସି ତାଲିକା CSV ଭାବେ ଡାଉନଲୋଡ୍ କରନ୍ତୁ, ବା ସମ୍ପୂର୍ଣ୍ଣ ମ୍ୟାଚ୍‌କୁ ଏକାଉଣ୍ଟାଣ୍ଟଙ୍କ ପାଇଁ PDF ଭାବେ ପ୍ରିଣ୍ଟ କରନ୍ତୁ।

ଏହା ଆପଣଙ୍କ ପାଇଁ କ’ଣ କରେ

  • ପୋର୍ଟାଲର ଦୁଇଟି ଫାଇଲ୍ ପଢେ: GSTR-2B JSON ଓ GSTR-2B Excel, ସେମାନଙ୍କ ଫିଲ୍ଡ ନାମ ଦ୍ୱାରା, ତେଣୁ ଫର୍ମାଟ୍‌ର ଛୋଟ ବଦଳରେ ଏହା ଅଟକେ ନାହିଁ।
  • ସପ୍ଲାୟର୍ GSTIN ଓ ବିଲ୍ ନମ୍ବର ଅନୁସାରେ ମିଳାଏ, ସ୍ପେସ୍, ସ୍ଲାଶ୍ ଓ ଆଗର ଶୂନ୍ୟ ଅଣଦେଖା କରି, ତା’ପରେ ଆପଣ ଅନୁମତି ଦେଇଥିବା ଅନ୍ତର ଭିତରେ ଟ୍ୟାକ୍ସେବଲ୍ ଭ୍ୟାଲୁ, ଟ୍ୟାକ୍ସ ଓ ତାରିଖ ଯାଞ୍ଚ କରେ।
  • ଟାଇପିଂ ଭେଦ ଖୋଜେ: ସମାନ ସପ୍ଲାୟର୍ ଓ ସମାନ ଅଙ୍କ କିନ୍ତୁ ଅଲଗା ବିଲ୍ ନମ୍ବର ଥିଲେ ତାହା “ନାହିଁ” ନୁହେଁ, ଅଲଗାକରି ଦେଖାଯାଏ।
  • କାହା ପଛରେ ପଡ଼ିବେ ଦେଖାଏ: 2B ରୁ ବାଦ୍ ପଡ଼ିଥିବା ବିଲ୍, ଆପଣଙ୍କ ଖାତାରୁ ବାଦ୍ ପଡ଼ିଥିବା ବିଲ୍, ITC ମିଳିବ ନାହିଁ ବୋଲି ଚିହ୍ନିତ ବିଲ୍, ଆଉ କିଛି ରିପୋର୍ଟ ନକରିଥିବା ସପ୍ଲାୟର୍।
  • IGST ବା CGST + SGST: ଯେଉଁ ବିଲ୍‌ରେ ଟ୍ୟାକ୍ସ ହେଡ୍ ଅଲଗା ତାହା ଚିହ୍ନାଏ, ଯାହା ପ୍ଲେସ୍ ଅଫ୍ ସପ୍ଲାଇ ଭୁଲ୍ ହେବାର ଏକ ସାଧାରଣ କାରଣ।
  • ସରକାରୀ ଟୁଲ୍ ପାଇଁ ପର୍ଚେଜ୍ ରେଜିଷ୍ଟର୍: GST ପୋର୍ଟାଲର Matching Offline Tool ଟେମ୍ପ୍ଲେଟ୍‌ର ଲେଆଉଟ୍‌ରେ ଆପଣଙ୍କ ବିଲ୍ ଡାଉନଲୋଡ୍ କରନ୍ତୁ।

ଆପଣଙ୍କ ଡାଟା ଆପଣଙ୍କ ପାଖରେ ହିଁ ରହେ

GSTR-2B ଫାଇଲ୍ ଏହି ବ୍ରାଉଜର୍ ଭିତରେ ହିଁ ଖୋଲା ଓ ପଢାଯାଏ। ଏହା ଆମକୁ ବା ଅନ୍ୟ କେଉଁଠି ଅପଲୋଡ୍ ହୁଏ ନାହିଁ, ଆଉ ସେଭ୍ ମଧ୍ୟ ହୁଏ ନାହିଁ: ପରବର୍ତ୍ତୀ ଥର ପୁଣି ଖୋଲନ୍ତୁ। ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍ ଆପଣଙ୍କ Nivesh Sahayak ଡାଟା ହୋମ୍ (my.niveshsahayak.in) ରୁ ଆସେ।

ଏକ ଯାଞ୍ଚ, ପରାମର୍ଶ ନୁହେଁ। ମ୍ୟାଚ୍ ଅନ୍ତର ଦେଖାଏ; କେଉଁ କ୍ରେଡିଟ୍ କ୍ଲେମ୍ କରିବେ ତାହା ସ୍ଥିର କରିବା ଆପଣଙ୍କ ହାତରେ। ସନ୍ଦେହ ହେଲେ ଆପଣଙ୍କ ଏକାଉଣ୍ଟାଣ୍ଟଙ୍କୁ ପଚାରନ୍ତୁ।

ଗାଇଡ୍

GSTR-2B ରିକନ୍ସିଲିଏସନ୍, ପାହାଚ ପାହାଚପ୍ରତ୍ୟେକ ଫଳର ଅର୍ଥ କ’ଣ ଓ କ’ଣ କରିବେ। GSTR-2B କିପରି ଡାଉନଲୋଡ୍ କରିବେପୋର୍ଟାଲରୁ JSON ବା Excel, ଓ IMS। GSTR-2B ଓ GSTR-2Aକେଉଁଟି ଆପଣଙ୍କ ITC ସ୍ଥିର କରେ, ଓ କାହିଁକି। ସପ୍ଲାୟର୍ GSTR-1 ଫାଇଲ୍ କରିନାହାଁନ୍ତିଆପଣଙ୍କ ITC ର କ’ଣ ହୁଏ ଓ କ’ଣ କରିବେ।

ଲୋକେ ପଚାରୁଥିବା ପ୍ରଶ୍ନ

ମୋ GSTR-2B ଫାଇଲ୍ କେଉଁଠି ଅପଲୋଡ୍ ହୁଏ କି?

ନା। ଏହା ଆପଣଙ୍କ ବ୍ରାଉଜର୍ ଭିତରେ ହିଁ ଖୋଲା ଓ ପଢାଯାଏ, ଆଉ କେଉଁଠି ସେଭ୍ ବା ପଠାଯାଏ ନାହିଁ।

କେଉଁ ଫାଇଲ୍ ଖୋଲିବି, JSON ନା Excel?

ଯେକୌଣସି। GST ପୋର୍ଟାଲର Returns Dashboard ରୁ GSTR-2B JSON ବା Excel ରେ ଡାଉନଲୋଡ୍ କରି ଏଠାରେ ଖୋଲନ୍ତୁ।

ମୋ ପର୍ଚେଜ୍ ବିଲ୍ କେଉଁଠାରୁ ଆସେ?

Nivesh Sahayak App ରେ ଆପଣ ଏଣ୍ଟ୍ରି କରିଥିବା ପର୍ଚେଜ୍ ବିଲ୍ ଓ ରିଟର୍ଣ୍ଣରୁ, ଯାହା ଏହି ବ୍ରାଉଜରର ଡାଟା ହୋମ୍‌ରେ ସେଭ୍ ଅଛି।

ବିଲ୍ କାହିଁକି “ନମ୍ବର ଅଲଗା” ଦେଖାଯାଏ?

ସପ୍ଲାୟର୍‌ଙ୍କ GSTIN ଓ ଅଙ୍କ ମିଳୁଛି କିନ୍ତୁ ବିଲ୍ ନମ୍ବର ଅଲଗା ଢଙ୍ଗରେ ଲେଖା, ଯେପରି “INV/45” ଓ “45”। ଆପଣଙ୍କ ଏଣ୍ଟ୍ରି ଠିକ୍ କରନ୍ତୁ, ଯେପରି ପରବର୍ତ୍ତୀ ଥର ମିଳିଯିବ।

ଏହାକୁ GST ପୋର୍ଟାଲର ନିଜସ୍ୱ ମ୍ୟାଚିଂ ଟୁଲ୍ ସହିତ ବ୍ୟବହାର କରିପାରିବି କି?

ହଁ। ପୋର୍ଟାଲର Matching Offline Tool ଟେମ୍ପ୍ଲେଟ୍‌ର ଲେଆଉଟ୍‌ରେ ଆପଣଙ୍କ ପର୍ଚେଜ୍ ବିଲ୍ ପାଇବା ପାଇଁ “GST ମ୍ୟାଚିଂ ଟୁଲ୍ ପାଇଁ ପର୍ଚେଜ୍ ରେଜିଷ୍ଟର୍” ଦବାନ୍ତୁ।

ଏହା ମାଗଣା କି?

ହଁ, ମାଗଣା, ଲଗଇନ୍ ନାହିଁ ଓ କୌଣସି ସୀମା ନାହିଁ।
