बेयाव GSTR-2B मिलाय माबादि खालामनाय

  1. नोंथांनि बायनाय बिलफोर सेभ खालाम। सापलाइयारनि बिल आरो बायनाय रिटार्नफोरखौ Nivesh Sahayak एपआव (app.niveshsahayak.in, “बायनाय आरो खरच”) एन्ट्रि खालाम। बेफोर बे ब्राउजारनि डेटा जायगायाव थायो।
  2. GSTR-2B डाउनलोड खालाम। GST पोर्टालआव: Services › Returns › Returns Dashboard, समा बाछि, आरो GSTR-2B टाइलआव Download बाछि (JSON एबा Excel)। नायमोन GSTR-2B माबादि डाउनलोड खालामनाय।
  3. फाइलखौ बेयाव खेव। नोंथांनि GSTR-2B फाइल खेव खौ क्लिक खालाम एबा बक्सआव डोबोन। नोंथांनि बायनाय बिलनि तारिख 2B समाव थायो; सिगांनि आफादनि बिल नायनो हागोन जायोब्ला बेखौ बांसिन खालाम।
  4. लिस्टफोर मोनसे मोनसे नायमोन। रासि एबा तारिख फारक आरो GSTR-2B आव दं, नोंथांनि बायनाय बिलआव गैया निफ्राय सुरु खालाम, उनाव बे GSTR-2B आव जेबो गैयाबाय सापलाइयारफोर नि अननि सापलाइयारफोरखौ फिन बुं।
  5. ठीक ITC क्लेम खालाम। “मिलायनाय ITC” टाइलआ सुरखित क्रेडिट। बेखौ GSTR-3B नि टेबल 4 आव बाहाय खालाम (खौसिन GSTR-3B हिसाब)।
  6. कपि थाय। जेबो लिस्टखौ CSV आव डाउनलोड खालाम, एबा गासै मिलायखौ अकाउन्टेन्टनि थाखाय PDF आव प्रिन्ट खालाम।

बेयो नोंथांनि थाखाय मा खालामो

  • पोर्टालनि नुवा फाइलखौ फरायो: GSTR-2B JSON आरो GSTR-2B Excel, बेफोरनि फिल्डनि मुं बाहायजों, बेनिखिनो गोख्रै फरमेट सोलायनायआ बेखौ बोखा खालाया।
  • सापलाइयारनि GSTIN आरो बिल नंजों मिलायो, स्पेस, स्लास आरो सुरुनि जिरोखौ नाजाया, उनाव नोंथां होनाय फारकनि गेजेराव टेक्सेबल भेल्यु, टेक्स आरो तारिख नायमोनो।
  • टाइप फारक सेंग्रायो: गुबुन सापलाइयार आरो गुबुन रासि गादोबो फारक बिल नं. बेखौ गैया बुंनायै गैया, गावथाइ नायहोयो।
  • माखौ फिन गोदान खालामो बे नायहोयो: 2B आव गैयाबाय बिल, नोंथांनि बुकआव गैयाबाय बिल, ITC उपलब्ध गैया चिन्हा जानाय, आरो जेबो रिपोर्ट खालामाखै सापलाइयारफोर।
  • IGST एबा CGST + SGST: टेक्स बोलोंआ फारक जायोब्ला बिलखौ चिन्हा खालामो, गोजाम नङा प्लेस अब सापलाइनि सासे कारन।
  • अधिकार जानाय टुलनि थाखाय बायनाय रेजिस्टार: GST पोर्टालनि Matching Offline Tool टेम्पलेटनि रूपआव नोंथांनि बिलफोर डाउनलोड खालाम।

नोंथांनि डेटा नोंथांजों

GSTR-2B फाइल बे ब्राउजारनि गेजेरावनै खेव जायो आरो फरा जायो। बेयो जोंनो एबा गुबुन जायगायाव दैथि जाया, आरो सेभबो जाया: उननि समाव फिन खेव। नोंथांनि बायनाय बिलफोर नोंथांनि Nivesh Sahayak डेटा जायगाफ्राय (my.niveshsahayak.in) आयो।

नायमोन, सुजा नङा। मिलायआ फारकफोरखौ नायहोयो; माबो क्रेडिट क्लेम खालामनो बे नोंथांनि निर्णय। सन्देह जायोब्ला नोंथांनि अकाउन्टेन्टखौ सुंनाय।

गाइडफोर

GSTR-2B मिलाय, मोनसे मोनसेमोनसे मोनसे रिजल्टआ मा बुंगासिन आरो माखौ खालामनो। GSTR-2B माबादि डाउनलोड खालामनायपोर्टालनिफ्राय JSON एबा Excel, आरो IMS। GSTR-2B आरो GSTR-2Aमाबोआ नोंथांनि ITC निर्णय खालामो, मानो। सापलाइयारआ GSTR-1 फाइल खालामाखैनोंथांनि ITC आव मा जायो आरो माखौ खालामनो।

गाहायफोरआ सुनाय सुंनाय

आंनि GSTR-2B फाइलखौ गुबुन जायगायाव आपलोड खालामो ला?

नङा। बेयो नोंथांनि ब्राउजारनि गेजेरावनै खेव जायो आरो फरा जायो आरो सेभ एबा दैथि जाया।

माबो फाइल खेवनो, JSON एबा Excel?

मोनसेबो जायो। GST पोर्टालनि Returns Dashboard फ्राय GSTR-2B JSON एबा Excel आव डाउनलोड खालाम आरो बेयाव खेव।

आंनि बायनाय बिलफोर माफ्राय आयो?

Nivesh Sahayak एपआव नोंथां एन्ट्रि खालामनाय बायनाय बिल आरो रिटार्नफ्राय, बे ब्राउजारनि डेटा जायगायाव सेभ जानायफ्राय।

बिल “नं. फारक” मानो नायो?

सापलाइयारनि GSTIN आरो रासिफोर मिलायो गादोबो बिल नंआ फारक लिरनाय, दृष्टान्त “INV/45” आरो “45”। नोंथांनि एन्ट्रिखौ ठीक खालाम, फिन मिलायगोन।

बेखौ GST पोर्टालनि गावनि मिलाय टुलजों बाहायनो हागोन ला?

हागोन। “GST मिलाय टुलनि थाखाय बायनाय रेजिस्टार” खौ क्लिक खालाम, पोर्टालनि Matching Offline Tool टेम्पलेटनि रूपआव नोंथांनि बायनाय बिलफोर मोनगोन।

बे फ्री ला?

दं, फ्री, लगिन गैया, सिमा गैया।
