GSTR-2B › GSTR-2B ಡೌನ್‌ಲೋಡ್

GSTR-2B ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದು ಹೇಗೆ

GSTR-2B ಎಂದರೆ ಒಂದು ತಿಂಗಳ ನಿಮ್ಮ ಇನ್‌ಪುಟ್ ಟ್ಯಾಕ್ಸ್ ಕ್ರೆಡಿಟ್ ಸ್ಟೇಟ್‌ಮೆಂಟ್; ನಿಮ್ಮ ಸಪ್ಲೈಯರ್‌ಗಳು ರಿಪೋರ್ಟ್ ಮಾಡಿದ್ದರಿಂದ ಪೋರ್ಟಲ್ ಇದನ್ನು ತಯಾರಿಸುತ್ತದೆ. ಇದು ಮುಂದಿನ ತಿಂಗಳ 14ನೇ ರಂದು ಸಿದ್ಧವಾಗುತ್ತದೆ.

GST ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಹಂತಗಳು

  1. www.gst.gov.in ನಲ್ಲಿ ಲಾಗಿನ್ ಮಾಡಿ.
  2. Services › Returns › Returns Dashboard ಗೆ ಹೋಗಿ.
  3. ಹಣಕಾಸು ವರ್ಷ ಮತ್ತು ರಿಟರ್ನ್ ಅವಧಿ ಆರಿಸಿ, ನಂತರ Search.
  4. GSTR-2B ಟೈಲ್‌ನಲ್ಲಿ Download ಆರಿಸಿ.
  5. Excel (ಓದಲು ಸುಲಭ) ಅಥವಾ JSON (ಪೂರ್ಣ) ಆರಿಸಿ. ಎರಡೂ ಮ್ಯಾಚರ್ ನಲ್ಲಿ ತೆರೆಯುತ್ತವೆ.

ತ್ರೈಮಾಸಿಕ (QRMP) ತೆರಿಗೆದಾರರಿಗೆ, ಪೋರ್ಟಲ್ ಪ್ರತಿ ತಿಂಗಳಿಗೂ ಮತ್ತು ತ್ರೈಮಾಸಿಕಕ್ಕೂ GSTR-2B ತಯಾರಿಸುತ್ತದೆ; ನೀವು ಪರಿಶೀಲಿಸಲು ಬಯಸುವುದಕ್ಕೆ ಹೊಂದುವುದನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.

ಇದು ಯಾವಾಗ ಸಿದ್ಧ?

ಒಂದು ತಿಂಗಳ GSTR-2B ಮುಂದಿನ ತಿಂಗಳ 14ನೇ ರಂದು ತಯಾರಾಗುತ್ತದೆ (CGST ನಿಯಮ 60(7)), ನಿಮ್ಮ ಸಪ್ಲೈಯರ್‌ಗಳು ಮತ್ತು ISD ಕಟ್-ಆಫ್ ವರೆಗೆ ಫೈಲ್ ಮಾಡಿದ GSTR-1, IFF, GSTR-1A, GSTR-5 ಮತ್ತು GSTR-6 ಯಿಂದ. ಕಟ್-ಆಫ್ ನಂತರ ರಿಪೋರ್ಟ್ ಮಾಡಿದ ಬಿಲ್ ಮುಂದಿನ ತಿಂಗಳ 2B ಗೆ ಹೋಗುತ್ತದೆ.

ಇನ್‌ವಾಯ್ಸ್ ಮ್ಯಾನೇಜ್‌ಮೆಂಟ್ ಸಿಸ್ಟಮ್ (IMS)

ಅಕ್ಟೋಬರ್ 2024 ರ ಅವಧಿಯಿಂದ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ Invoice Management System ಇದೆ. GSTR-3B ಫೈಲ್ ಮಾಡುವ ಮೊದಲು ಪ್ರತಿ ಸಪ್ಲೈಯರ್ ಬಿಲ್ ಅನ್ನು ಅಕ್ಸೆಪ್ಟ್, ರಿಜೆಕ್ಟ್ ಅಥವಾ ಪೆಂಡಿಂಗ್ ಇಡಬಹುದು. ಅಕ್ಸೆಪ್ಟ್ ಮಾಡಿದ (ಮತ್ತು ಯಾವ ಕ್ರಮವೂ ಇಲ್ಲದ) ಬಿಲ್‌ಗಳು GSTR-2B ಯಲ್ಲಿ ಲೆಕ್ಕಕ್ಕೆ ಬರುತ್ತವೆ; ರಿಜೆಕ್ಟ್ ಮಾಡಿದ ಬಿಲ್‌ಗಳು ಹೊರಗೆ ಹೋಗುತ್ತವೆ; ಪೆಂಡಿಂಗ್ ಬಿಲ್‌ಗಳು ಮುಂದಿನ ತಿಂಗಳಿಗೆ ಕಾಯುತ್ತವೆ. IMS ನಲ್ಲಿ ಕ್ರಮ ತೆಗೆದುಕೊಂಡ ನಂತರ GSTR-3B ಫೈಲ್ ಮಾಡುವ ಮೊದಲು GSTR-2B ಅನ್ನು ಮತ್ತೆ ತಯಾರಿಸಬಹುದು. ಮ್ಯಾಚ್ ಅಂತಿಮ ಅಂಕಿಗಳನ್ನು ತೋರಿಸುವಂತೆ 2B ಅನ್ನು IMS ಕ್ರಮಗಳ ನಂತರ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.

ಫೈಲ್‌ನಲ್ಲಿ ಏನಿದೆ

  • B2B ಇನ್‌ವಾಯ್ಸ್‌ಗಳು ಮತ್ತು ಅವುಗಳ ತಿದ್ದುಪಡಿಗಳು, ಕ್ರೆಡಿಟ್ ಮತ್ತು ಡೆಬಿಟ್ ನೋಟ್‌ಗಳು, ಸರಕುಗಳ ಆಮದು (ICEGATE ಯಿಂದ), ISD ಕ್ರೆಡಿಟ್.
  • ಪ್ರತಿ ಬಿಲ್‌ಗೆ: ಸಪ್ಲೈಯರ್ GSTIN ಮತ್ತು ಹೆಸರು, ನಂಬರ್, ದಿನಾಂಕ, ಮೌಲ್ಯ, ಪ್ಲೇಸ್ ಆಫ್ ಸಪ್ಲೈ, ರಿವರ್ಸ್ ಚಾರ್ಜ್, ಟ್ಯಾಕ್ಸಬಲ್ ವ್ಯಾಲ್ಯೂ, IGST, CGST, SGST, ಸೆಸ್, ITC ಲಭ್ಯವೇ ಇಲ್ಲವೇ, ಇಲ್ಲವಾದರೆ ಕಾರಣ, ಮತ್ತು ಸಪ್ಲೈಯರ್ ಯಾವಾಗ ಫೈಲ್ ಮಾಡಿದರು.

ಖಾಸಗಿಯಾಗಿ ಇಡಿ

ಫೈಲ್‌ನಲ್ಲಿ ನಿಮ್ಮ ಖರೀದಿಗಳು ಮತ್ತು ಸಪ್ಲೈಯರ್‌ಗಳ ಪಟ್ಟಿ ಇರುತ್ತದೆ. ಮ್ಯಾಚರ್ ಅದನ್ನು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನೊಳಗೇ ಓದುತ್ತದೆ, ಎಲ್ಲಿಗೂ ಕಳುಹಿಸುವುದಿಲ್ಲ; ಸೇವ್ ಕೂಡ ಮಾಡುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿದ ಫೈಲ್ ಅನ್ನು ನಿಮ್ಮ ದಾಖಲೆಗಾಗಿ ಸುರಕ್ಷಿತ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇಡಿ.

ಈ ತಿಂಗಳ GSTR-2B ಅನ್ನು ನಿಮ್ಮ ಬಿಲ್‌ಗಳ ಜೊತೆ ಈಗಲೇ ಮ್ಯಾಚ್ ಮಾಡಿ.ಮೇಕರ್ ತೆರೆಯಿರಿ
