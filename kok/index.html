तुमच्या खरेदी बिलांखातीर फुकट GSTR-2B मॅचर

GST पोर्टलावयल्यान GSTR-2B देंवयात, हांगा उगडात, आनी तुमच्या बुकांकडेन कितलीं पुरवणदार बिलां मेळटात, कितलीं वेगळीं, कितलीं दोनूय वटींनी उणीं आनी कोणे पुरवणदार भरूंक नाशिले तें लगेच पळयात. फायल तुमच्या ब्राउझरांतल्यान भायर वचना.

हांगा GSTR-2B मॅच कशें करचें

  1. तुमचीं खरेदी बिलां सेव करात. पुरवणदार बिलां आनी खरेदी रिटर्न Nivesh Sahayak App (app.niveshsahayak.in, “Purchases and expenses”) आंत एंट्री करात. तीं ह्या ब्राउझराच्या डेटा होमांत उरतात.
  2. GSTR-2B देंवयात. GST पोर्टलार: Services › Returns › Returns Dashboard, कालावधी वेंचात, आनी GSTR-2B टाईलांत Download (JSON वा Excel) वेंचात. GSTR-2B कशें देंवयचें पळयात.
  3. फायल हांगा उगडात. Open your GSTR-2B file दाबात वा फायल बॉक्सार सोडात. तुमच्या खरेदी बिलांच्यो तारखो 2B कालावधी प्रमाण ठेयल्यात; फाटल्या म्हयन्यांचीं बिलां येवंक शकतात जाल्यार तांकां वाडयात.
  4. याद्यांतल्यान वचात. Amount or date differs आनी In GSTR-2B, not in your purchase bills पासून सुरू करात, उपरांत Suppliers with nothing in this GSTR-2B खाला दिल्ल्या पुरवणदारांक याद करून दिवयात.
  5. बरो ITC घेयात. “ITC matched” टाईल सुरक्षीत क्रेडिट. तें GSTR-3B च्या टेबल 4 आंत वापरात (GSTR-3B वर्कींग करून पळयात).
  6. एक कॉपी दवरात. खंयचीय यादी CSV म्हणून देंवयात, वा पुरो मॅच तुमच्या अकाउंटंटाखातीर PDF म्हणून प्रिंट करात.

तुमखातीर हें कितें करता

  • पोर्टलाच्यो दोनूय फायली वाचता: GSTR-2B JSON आनी GSTR-2B Excel, तांच्या फील्डाच्या नांवांवयल्यान, देखून ल्हान फॉरमॅट बदलांनी तें मोडना.
  • पुरवणदाराच्या GSTIN आनी बिल नंबरावयल्यान मेळयता, स्पेस, स्लॅश आनी सुरवेचे शून्य सोडून, उपरांत तुमी दिल्ल्या फरकामेरेन टॅक्सेबल व्हॅल्यू, टॅक्स आनी तारीख तपासता.
  • टायपिंगाचे फरक सोदता: एकूच पुरवणदार आनी एकूच रक्कम पूण वेगळो बिल नंबर वेगळो दाखयता, उणें म्हणून न्हय.
  • कितें फाटल्यान लागचें तें दाखयता: 2B आंतलीं उणीं बिलां, तुमच्या बुकांतलीं उणीं बिलां, ITC मेळना अशें खूण केल्लीं बिलां, आनी कांयच रिपोर्ट केलां नाशिले पुरवणदार.
  • IGST वा CGST + SGST: टॅक्स हेड वेगळो आशिल्लीं बिलां खूण करता, चुकीच्या प्लेस ऑफ सप्लायाचें सादारण कारण.
  • अधिकृत टूलाखातीर खरेदी रजिस्टर: तुमचीं बिलां GST पोर्टलाच्या Matching Offline Tool टेम्प्लेटाच्या फॉरमॅटांत देंवयात.

तुमचो डेटा तुमचेकडेच उरता

GSTR-2B फायल ह्या ब्राउझरांतूच उगडतात आनी वाचतात. ती आमकां वा हेर खंयच अपलोड जायना, आनी सेवय सुद्धां जायना: फुडल्या फावटी परतून उगडात. तुमचीं खरेदी बिलां तुमच्या Nivesh Sahayak डेटा होमांतल्यान येतात (my.niveshsahayak.in).

तपासणी, सल्लो न्हय. मॅच फरक दाखयता; खंयचें क्रेडिट घेवचें तें तुमच्या हातांत. संशय आसल्यार तुमच्या अकाउंटंटाक विचारात.

मार्गदर्शक

GSTR-2B रिकन्सिलिएशन, पावला पावलानदर निकालाचो अर्थ आनी कितें करचें. GSTR-2B कशें देंवयचेंपोर्टलावयल्यान JSON वा Excel, आनी IMS. GSTR-2B आनी GSTR-2Aतुमचो ITC खंयचो ठरयता, आनी कित्याक. पुरवणदारान GSTR-1 भरलो नातुमच्या ITC चें कितें जाता आनी कितें करचें.

लोक विचारपी प्रस्न

म्हजी GSTR-2B फायल खंय अपलोड जाता?

ना. ती तुमच्या ब्राउझरांतूच उगडतात आनी वाचतात, आनी खंयच सेव वा धाडनात.

खंयची फायल उगडची, JSON वा Excel?

दोनूय चलतात. GSTR-2B GST पोर्टलाच्या Returns Dashboard वयल्यान JSON वा Excel मदीं देंवयात आनी हांगा उगडात.

म्हजीं खरेदी बिलां खंयच्यान येतात?

तुवें Nivesh Sahayak App आंत एंट्री केल्ल्या खरेदी बिलां आनी रिटर्नांतल्यान, ह्या ब्राउझराच्या डेटा होमांत सेव केल्ल्यांतल्यान.

बिल “number differs” अशें कित्याक दिसता?

पुरवणदाराचो GSTIN आनी रकमो जुळटात पूण बिलाचो नंबर वेगळ्यान बरयला, देखीक “INV/45” आनी “45”. फुडल्या फावटी मेळ जावंक तुमची एंट्री सुदारात.

GST पोर्टलाच्या स्वताच्या मॅचिंग टूलाकडेन हें वापरूं येता?

हय. तुमचीं खरेदी बिलां पोर्टलाच्या Matching Offline Tool टेम्प्लेटाच्या फॉरमॅटांत मेळपाक “Purchase register for the GST matching tool” दाबात.

हें फुकट?

हय, फुकट, लॉगीन ना आनी मर्यादा ना.
