هتي GSTR-2B ميچ ڪيئن ڪجي

  1. پنهنجا خريداري بل سيو ڪريو. سپلائرن جا بل ۽ خريداري واپسيون Nivesh Sahayak App (app.niveshsahayak.in، "خريداريون ۽ خرچ") ۾ لکو. اهي هن برائوزر جي ڊيٽا هوم ۾ رهن ٿا.
  2. GSTR-2B ڊائونلوڊ ڪريو. GST پورٽل تي: Services › Returns › Returns Dashboard، مدو چونڊيو، ۽ GSTR-2B ٽائل ۾ Download (JSON يا Excel) چونڊيو. GSTR-2B ڪيئن ڊائونلوڊ ڪجي ڏسو.
  3. فائل هتي کوليو. پنهنجي GSTR-2B فائل کوليو دٻايو يا فائل خاني تي ڇڏيو. توهان جي خريداري بلن جون تاريخون 2B جي مدي تي سيٽ ٿين ٿيون؛ جيڪڏهن اڳين مهينن جا بل اچي سگهن ٿا ته ان کي وسيع ڪريو.
  4. فهرستن مان گذرو. رقم يا تاريخ ۾ فرق ۽ GSTR-2B ۾ آهي، توهان جي خريداري بلن ۾ ناهي کان شروع ڪريو، پوءِ سپلائر جن جو هن GSTR-2B ۾ ڪجهه به ناهي هيٺ ڏيکاريل سپلائرن کي ياد ڏياريو.
  5. صحيح ITC ڪلير ڪريو. "ميچ ٿيل ITC" ٽائل محفوظ ڪريڊٽ آهي. ان کي GSTR-3B جي ٽيبل 4 ۾ استعمال ڪريو (GSTR-3B ورڪنگ آزمايو).
  6. ڪاپي رکو. ڪنهن به فهرست کي CSV طور ڊائونلوڊ ڪريو، يا سڄو ميچ اڪائونٽنٽ لاءِ PDF طور پرنٽ ڪريو.

هي توهان لاءِ ڇا ڪري ٿو

  • پورٽل جون ٻئي فائلون پڙهي ٿو: GSTR-2B JSON ۽ GSTR-2B Excel، فيلڊن جي نالن سان، ته جيئن ننڍيون فارميٽ تبديليون ان کي خراب نه ڪن.
  • سپلائر جي GSTIN ۽ بل نمبر سان ميچ ڪري ٿو، خالي جاءِ، سليش ۽ اڳيان صفر نظرانداز ڪري، پوءِ توهان جي ڏنل فرق اندر ٽيڪس لائق ويليو، ٽيڪس ۽ تاريخ چيڪ ڪري ٿو.
  • ٽائيپنگ جا فرق ڳولي ٿو: ساڳيو سپلائر ۽ ساڳي رقم پر مختلف بل نمبر، ڳولجڻ کان ڇڏيل نه پر الڳ ڏيکاريو وڃي ٿو.
  • ڇا پٺيان لڳڻو آهي ڏيکاري ٿو: 2B کان غائب بل، توهان جي کاتن کان غائب بل، ITC دستياب ناهي چيل بل، ۽ جن سپلائرن ڪجهه به رپورٽ نه ڪيو.
  • IGST يا CGST + SGST: جن بلن ۾ ٽيڪس هيڊ مختلف آهي تن کي نشان لڳائي ٿو، جيڪو غلط پليس آف سپلائي جو عام سبب آهي.
  • سرڪاري ٽول لاءِ خريداري رجسٽر: GST پورٽل جي Matching Offline Tool ٽيمپليٽ جي ترتيب ۾ پنهنجا بل ڊائونلوڊ ڪريو.

توهان جو ڊيٽا توهان وٽ ئي رهي ٿو

GSTR-2B فائل هن برائوزر اندر کوليو ۽ پڙهيو وڃي ٿو. اها اسان ڏانهن يا ٻئي ڪٿي اپ لوڊ نٿي ٿئي، ۽ سيو به نٿي ٿئي: ايندڙ ڀيري ٻيهر کوليو. توهان جا خريداري بل توهان جي Nivesh Sahayak ڊيٽا هوم (my.niveshsahayak.in) مان اچن ٿا.

چيڪ آهي، صلاح ناهي. ميچ فرق ڏيکاري ٿو؛ ڪهڙو ڪريڊٽ ڪلير ڪجي، اهو فيصلو توهان جو آهي. شڪ هجي ته پنهنجي اڪائونٽنٽ کان پڇو.

گائيڊون

GSTR-2B ريڪنسليئيشن، قدم بقدمهر نتيجي جو مطلب ۽ ڇا ڪجي. GSTR-2B ڪيئن ڊائونلوڊ ڪجيپورٽل تان JSON يا Excel، ۽ IMS. GSTR-2B ۽ GSTR-2Aتوهان جو ITC ڪير طئي ڪري ٿو، ۽ ڇو. سپلائر GSTR-1 فائل نه ڪيو آهيITC سان ڇا ٿئي ٿو ۽ ڇا ڪجي.

ماڻهن جا سوال

ڇا منهنجي GSTR-2B فائل ڪٿي اپ لوڊ ٿئي ٿي؟

نه. اها توهان جي برائوزر اندر کوليو ۽ پڙهيو وڃي ٿو ۽ ڪٿي به سيو يا موڪليو نٿو وڃي.

ڪهڙي فائل کوليان، JSON يا Excel؟

ٻنهي مان ڪا به. GST پورٽل جي Returns Dashboard تان GSTR-2B JSON يا Excel ۾ ڊائونلوڊ ڪري هتي کوليو.

منهنجا خريداري بل ڪٿان اچن ٿا؟

Nivesh Sahayak App ۾ توهان جي لکيل خريداري بلن ۽ واپسين مان، جيڪي هن برائوزر جي ڊيٽا هوم ۾ سيو ٿين ٿا.

بل "نمبر مختلف" ڇو ڏيکاريل آهي؟

سپلائر جو GSTIN ۽ رقمون ملن ٿيون پر بل نمبر مختلف طرح لکيل آهي، مثال "INV/45" ۽ "45". ايندڙ ڀيري ملڻ لاءِ پنهنجي انٽري درست ڪريو.

ڇا هي GST پورٽل جي پنهنجي ميچنگ ٽول سان استعمال ڪري سگهجي ٿو؟

ها. "GST ميچنگ ٽول لاءِ خريداري رجسٽر" دٻايو ته توهان جا خريداري بل پورٽل جي Matching Offline Tool ٽيمپليٽ جي ترتيب ۾ ملندا.

ڇا هي مفت آهي؟

ها، مفت، لاگ ان ناهي ۽ ڪابه حد ناهي.
